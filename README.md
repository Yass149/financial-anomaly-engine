# financial-anomaly-engine
# Quantitative Risk & Behavioural Fraud Engine (MSc Thesis)

🔒 **Status: Code under Academic Embargo**
*This repository contains the architecture and methodology for my ongoing MSc Data Science thesis at the University of Reading. To comply with academic integrity policies, the source code is kept in a private repository and will be made public upon graduation in September 2026.*

## Overview
An end-to-end machine learning system designed to detect anomalies within massive, highly imbalanced financial transaction datasets. Engineered to handle high-throughput sequential data with enterprise-grade reliability and transparency.

## Architecture & Tech Stack
* **Deep Learning Framework:** PyTorch 
* **Data Engineering & Acceleration:** Python, NVIDIA cuDF (GPU-accelerated DataFrames)
* **Explainable AI (XAI):** Captum (integrated to translate complex neural network outputs into transparent risk assessments)
* **Deployment Environment:** HPC UNIX Cluster
